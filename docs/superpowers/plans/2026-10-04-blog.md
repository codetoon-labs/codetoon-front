# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an SEO-focused, bilingual (en/ar) blog: posts and categories managed in Filament, served over GraphQL, rendered by Next.js at `/blog`, `/blog/<slug>` and `/blog/category/<slug>` (mirrored under `/ar`), with full structured data and sitemap coverage.

**Architecture:** The Laravel CMS stores posts with spatie-translatable fields, sanitises the article HTML on save, and exposes live posts only through Lighthouse GraphQL, with translatable fields returned as `{ en ar }`. The Next.js site fetches once per page, localises with `localize()`, renders with ISR (`revalidate = 300`), and redirects untranslated Arabic posts to English.

**Tech Stack:**
- **Backend:** Laravel 12, Filament 4.3 with lara-zeus spatie-translatable, nuwave/lighthouse 6.65, spatie/laravel-translatable 6.13, spatie/laravel-tags, spatie/laravel-medialibrary, symfony/html-sanitizer 7.4, Pest.
- **Frontend:** Next.js 15 App Router on OpenNext/Cloudflare, Apollo Client 4, Tailwind 4, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-10-04-blog-design.md` (in `codetoon-front`)

**Spec amendment (made while planning):** pagination uses path segments (`/blog/page/2`, `/blog/category/<slug>/page/2`) instead of `?page=2`. In Next 15, reading `searchParams` makes a page dynamic, which would bypass the 5-minute ISR cache and hit the CMS on every request. Path pages cache normally and give each page a clean canonical. `/blog/page/1` permanently redirects to `/blog`.

## Global Constraints

- Two repos.
  - **Backend:** `~/Herd/codetoon`. Work in a worktree at `~/Herd/codetoon-blog-wt` on branch `feature/blog`, created from `origin/master`.
  - **Frontend:** `~/Herd/codetoon-front` on branch `feature/blog`, which already contains the spec.
- Backend migrations must run on **PostgreSQL, MySQL and SQLite**. Use `$table->json()`, never raw SQL. JSON queries go through the query builder's `column->key` syntax.
- Translatable backend fields return `Translation { en ar }` via `@translations`; `null` means not translated.
- Supported locales come from `config('app.supported_locales')` (`['en', 'ar']`) in the backend and `locales` in `lib/i18n/config.ts` in the frontend.
- Slugs are English-only and shared by both languages. The URL keys are `blog_posts.slug` and `blog_categories.slug`.
- A post is **live** when `status = 'published' AND published_at <= now()`. Nothing that isn't live is ever returned by GraphQL.
- A post is **available in a locale** when that locale's `title` and `body` are both non-empty. English is required, so live posts are always available in `en`.
- Blog pages, the sitemap and `llms.txt` use `revalidate = 300`. The rest of the site stays at 3600.
- Untranslated Arabic posts: `/ar/blog/<slug>` gets a **307** redirect to `/blog/<slug>`. Arabic listings only include Arabic-available posts. hreflang and the sitemap only include available locales.
- Frontend copy lives in `lib/i18n/messages/{en,ar}/blog.ts`. The Arabic file is typed against the English one and must not leave English strings empty (enforced by `messages.test.ts`).
- English pages that exist today must render unchanged, except for the new "Blog" nav and footer links.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

These are inputs the spec implies but doesn't spell out. Each one is pinned by a test in the task named.

1. **Very long articles (> 20,000 characters).** Symfony's sanitizer silently truncates input past its default max length. A 60,000-character article must survive intact (Task 1).
2. **Headings that slugify to nothing or collide.** A heading that's only punctuation, emoji-only headings, or two identical Arabic headings must still get unique, non-empty ids (Task 1).
3. **Deleted categories and authors.** If a post's category or author is deleted, the post stays live with `category`/`author` null. The page and JSON-LD fall back to the organization as author, and nothing crashes (Tasks 2 and 9).
4. **Arabic pages linking to English-only posts.** Arabic related posts, listings and cards must never link to `/ar/blog/<slug>` for an English-only post (Tasks 3 and 8).
5. **Schedule time zone.** Editors in Cairo enter local times. `published_at` must be stored in UTC from a Cairo-time picker, so a 09:00 schedule doesn't go live two hours early or late (Task 5).

`app/Support/ArticleHtml.php`:

```php
<?php

namespace App\Support;

use DOMDocument;
use Symfony\Component\HtmlSanitizer\HtmlSanitizer;
use Symfony\Component\HtmlSanitizer\HtmlSanitizerConfig;

/**
 * Blog article HTML: what editors write in the RichEditor, reduced to a safe
 * subset, with stable ids on every H2 so the website can build a table of
 * contents and link to sections.
 */
final class ArticleHtml
{
    private const WORDS_PER_MINUTE = 200;

    /** Articles can be long; Symfony's default input cap (20k chars) would truncate them. */
    private const MAX_INPUT_LENGTH = 1_000_000;

    private const BLOCK_ELEMENTS = [
        'h2', 'h3', 'h4', 'p', 'br', 'strong', 'em', 'u', 's', 'ul', 'ol', 'li', 'blockquote',
        'code', 'pre', 'figure', 'figcaption', 'table', 'thead', 'tbody', 'tr', 'hr',
    ];

    public static function clean(?string $html): ?string
    {
        if ($html === null || trim($html) === '') {
            return null;
        }

        $clean = trim(self::sanitizer()->sanitize($html));

        return $clean === '' ? null : self::anchorHeadings($clean);
    }

    public static function readingTime(?string $html): ?int
    {
        $text = trim(html_entity_decode(strip_tags((string) $html), ENT_QUOTES | ENT_HTML5, 'UTF-8'));

        if ($text === '') {
            return null;
        }

        $words = count(preg_split('/\s+/u', $text, -1, PREG_SPLIT_NO_EMPTY));

        return max(1, (int) ceil($words / self::WORDS_PER_MINUTE));
    }

    /** Unicode-aware: Arabic headings keep Arabic ids. */
    public static function slugify(string $text): string
    {
        $slug = preg_replace('/[^\p{L}\p{N}]+/u', '-', mb_strtolower(trim($text), 'UTF-8'));

        return trim((string) $slug, '-') ?: 'section';
    }

    private static function sanitizer(): HtmlSanitizer
    {
        $config = (new HtmlSanitizerConfig())
            ->withMaxInputLength(self::MAX_INPUT_LENGTH)
            ->allowLinkSchemes(['https', 'http', 'mailto', 'tel'])
            ->allowRelativeLinks()
            ->allowMediaSchemes(['https', 'http'])
            ->allowRelativeMedias()
            ->forceAttribute('a', 'rel', 'noopener noreferrer');

        foreach (self::BLOCK_ELEMENTS as $element) {
            $config = $config->allowElement($element);
        }

        $config = $config
            ->allowElement('a', ['href', 'title', 'target'])
            ->allowElement('img', ['src', 'alt', 'width', 'height'])
            ->allowElement('th', ['colspan', 'rowspan'])
            ->allowElement('td', ['colspan', 'rowspan']);

        return new HtmlSanitizer($config);
    }

    private static function anchorHeadings(string $html): string
    {
        if (stripos($html, '<h2') === false) {
            return $html;
        }

        $document = new DOMDocument();
        $previous = libxml_use_internal_errors(true);
        $document->loadHTML(
            '<?xml encoding="utf-8"?><div>'.$html.'</div>',
            LIBXML_HTML_NOIMPLIED | LIBXML_HTML_NODEFDTD
        );
        libxml_clear_errors();
        libxml_use_internal_errors($previous);

        $used = [];
        foreach ($document->getElementsByTagName('h2') as $heading) {
            $base = self::slugify($heading->textContent);
            $id = $base;
            for ($n = 2; isset($used[$id]); $n++) {
                $id = "{$base}-{$n}";
            }
            $used[$id] = true;
            $heading->setAttribute('id', $id);
        }

        $wrapper = $document->getElementsByTagName('div')->item(0);
        $out = '';
        foreach ($wrapper->childNodes as $child) {
            $out .= $document->saveHTML($child);
        }

        return $out;
    }
}
```

```php
            'seo_description' => 'array',

    public function posts(): HasMany
    {
        return $this->hasMany(BlogPost::class);

    public function livePosts(): HasMany
    {
        return $this->posts()->live();

    public function scopeOrderedBySortOrder(Builder $query): Builder
    {
        return $query->orderBy('sort_order')->orderBy('id');
```

```php
            'published_at' => 'datetime',
        ];
    }

    protected static function booted(): void
    {
        static::saving(function (BlogPost $post) {
            if ($post->status === self::STATUS_PUBLISHED && $post->published_at === null) {
                $post->published_at = now();
            }

            if ($post->isDirty('body')) {
                $bodies = [];
                $times = [];
                foreach ($post->getTranslations('body') as $locale => $html) {
                    if ($clean = ArticleHtml::clean($html)) {
                        $bodies[$locale] = $clean;
                        $times[$locale] = ArticleHtml::readingTime($clean);
                    }
                }
                $post->replaceTranslations('body', $bodies);
                $post->replaceTranslations('reading_time', $times);
            }

            if ($post->isDirty('faqs')) {
                $faqs = [];
                foreach ($post->getTranslations('faqs') as $locale => $rows) {
                    $kept = collect(is_array($rows) ? $rows : [])
                        ->map(fn ($row) => [
                            'question' => trim((string) ($row['question'] ?? '')),
                            'answer' => trim((string) ($row['answer'] ?? '')),
                        ])
                        ->filter(fn (array $row) => $row['question'] !== '' && $row['answer'] !== '')
                        ->values()
                        ->all();
                    if ($kept) {
                        $faqs[$locale] = $kept;
                    }
                }
                $post->replaceTranslations('faqs', $faqs);
            }
        });
    }

    public function registerMediaCollections(): void
    {
        $this->addMediaCollection('cover')->singleFile();
    }

    public function cover(): MorphOne
    {
        return $this->morphOne(config('media-library.media_model'), 'model')
            ->where('collection_name', 'cover');
    }

    public function category(): BelongsTo
    {
        return $this->belongsTo(BlogCategory::class, 'blog_category_id');
    }

    public function author(): BelongsTo
    {
        return $this->belongsTo(Team::class, 'author_id');
    }

    /** Published, and the publish date has passed (future dates are scheduled). */
    public function scopeLive(Builder $query): Builder
    {
        return $query->where('status', self::STATUS_PUBLISHED)
            ->whereNotNull('published_at')
            ->where('published_at', '<=', now());
    }

    /** Has a title and body in $locale. JSON paths compile on pgsql, mysql and sqlite. */
    public function scopeAvailableIn(Builder $query, string $locale): Builder
    {
        return $query->whereNotNull("title->{$locale}")->where("title->{$locale}", '!=', '')
            ->whereNotNull("body->{$locale}")->where("body->{$locale}", '!=', '');
    }

    public function isAvailableIn(string $locale): bool
    {
        return filled($this->getTranslation('title', $locale, false))
            && filled($this->getTranslation('body', $locale, false));
    }

    /** @return array<int, string> */
    public function availableLocales(): array
    {
        return array_values(array_filter(
            config('app.supported_locales'),
            fn (string $locale) => $this->isAvailableIn($locale),
        ));
    }
```

```php
<?php

namespace App\GraphQL\Queries;

use App\Models\BlogPost;
use App\Support\Translations;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Support\Collection;
use Spatie\Tags\Tag;

final readonly class BlogPosts
{
    public function builder(mixed $root, array $args): Builder
    {
        $locale = $args['locale'] ?? null;

        return BlogPost::query()
            ->live()
            ->when($args['category'] ?? null, fn (Builder $q, string $slug) => $q->whereHas('category', fn (Builder $c) => $c->where('slug', $slug)))
            ->when($args['tag'] ?? null, fn (Builder $q, string $tag) => $q->withAnyTags([$tag]))
            // Only known locales reach the JSON path.
            ->when(in_array($locale, config('app.supported_locales'), true), fn (Builder $q) => $q->availableIn($locale))
            ->orderByDesc('published_at')
            ->orderByDesc('id');
    }

    public function related(mixed $root, array $args): Collection
    {
        $post = BlogPost::query()->live()->where('slug', $args['slug'])->first();

        if (! $post) {
            return collect();
        }

        $tagIds = $post->tags()->pluck('tags.id');

        return BlogPost::query()
            ->live()
            ->whereKeyNot($post->getKey())
            ->withCount(['tags as shared_tags' => fn (Builder $q) => $q->whereIn('tags.id', $tagIds)])
            ->orderByRaw('CASE WHEN blog_category_id = ? THEN 0 ELSE 1 END', [$post->blog_category_id ?? 0])
            ->orderByDesc('shared_tags')
            ->orderByDesc('published_at')
            ->limit(max(1, min(12, (int) ($args['first'] ?? 3))))
            ->get();
    }

    /** @return array<string, array<int, array{question: string, answer: string}>|null> */
    public function faqs(BlogPost $post, array $args): array
    {
        return Translations::of($post, 'faqs', fn ($rows): ?array => is_array($rows) && $rows ? array_values($rows) : null);
    }

    /** @return array<string, int|null> */
    public function readingTime(BlogPost $post, array $args): array
    {
        return Translations::of($post, 'reading_time');
    }

    /** @return array<int, array<string, ?string>> */
    public function tags(BlogPost $post, array $args): array
    {
        return $post->tags->map(fn (Tag $tag): array => Translations::of($tag, 'name'))->all();
    }
}
```

```ts
import type { MetadataRoute } from 'next';
import { absoluteUrl, defaultLocale, type Locale } from '@/lib/i18n/config';
import type { BlogPostCard } from '@/lib/blog-data';

// Pure helpers shared by the blog pages, sitemap and llms.txt.

export type TocItem = { id: string; text: string };

/** Fewer section headings than this and the table of contents isn't worth showing. */
export const MIN_TOC_HEADINGS = 3;

const ENTITIES: Record<string, string> = { amp: '&', lt: '<', gt: '>', quot: '"', '#39': "'", nbsp: ' ' };

function decodeEntities(value: string): string {
    return value
        .replace(/&(amp|lt|gt|quot|#39|nbsp);/g, (_, name) => ENTITIES[name])
        .replace(/&#(\d+);/g, (_, code) => String.fromCodePoint(Number(code)));
}

/** H2s with ids (added by the CMS on save) become the table of contents. */
export function extractToc(html: string | null | undefined): TocItem[] {
    if (!html) return [];
    return [...html.matchAll(/<h2\b[^>]*\bid="([^"]+)"[^>]*>([\s\S]*?)<\/h2>/gi)]
        .map(([, id, inner]) => ({
            id,
            text: decodeEntities(inner.replace(/<[^>]+>/g, '')).replace(/\s+/g, ' ').trim(),
        }))
        .filter((item) => item.text !== '');
}

export function shouldRedirectToEnglish(available: readonly string[], locale: Locale): boolean {
    return locale !== defaultLocale && !available.includes(locale);
}

/** Arabic pages must never link to an Arabic URL that redirects away. */
export function onlyAvailableIn<T extends { available_locales: readonly string[] }>(posts: T[], locale: Locale): T[] {
    return posts.filter((post) => post.available_locales.includes(locale));
}

export function blogPostPath(slug: string): string {
    return `/blog/${slug}`;
}

export function blogListPath(page: number, category?: string): string {
    const base = category ? `/blog/category/${category}` : '/blog';
    return page > 1 ? `${base}/page/${page}` : base;
}

/** "/blog/page/<n>": only canonical integers above 1 (page 1 is the bare URL). */
export function parseListingPage(raw: string): number | null {
    return /^[1-9]\d*$/.test(raw) && Number(raw) > 1 ? Number(raw) : null;
}

/** CMS datetimes are "Y-m-d H:i:s" in UTC (or plain "Y-m-d"). */
export function parseCmsDate(value: string): Date {
    return new Date(value.includes(' ') ? `${value.replace(' ', 'T')}Z` : `${value}T00:00:00Z`);
}

export function formatBlogDate(value: string, locale: Locale): string {
    return new Intl.DateTimeFormat(locale === 'ar' ? 'ar-EG' : 'en-US', { dateStyle: 'long', timeZone: 'UTC' }).format(parseCmsDate(value));
}

/** Sitemap entries for the blog; Arabic URLs only where Arabic content exists. */
export function blogSitemapEntries(posts: BlogPostCard[], categories: { slug: string }[]): MetadataRoute.Sitemap {
    const localesFor = (arabicPosts: BlogPostCard[]): Locale[] => (arabicPosts.length ? ['en', 'ar'] : ['en']);
    const arabic = posts.filter((p) => p.available_locales.includes('ar'));

    const entry = (path: string, available: Locale[], lastModified?: Date, priority = 0.6): MetadataRoute.Sitemap => {
        const languages = Object.fromEntries(available.map((l) => [l, absoluteUrl(path, l)]));
        return available.map((locale) => ({
            url: absoluteUrl(path, locale),
            lastModified,
            changeFrequency: 'weekly' as const,
            priority,
            alternates: { languages },
        }));
    };

    return [
        ...entry('/blog', localesFor(arabic), undefined, 0.8),
        ...categories.flatMap((c) => entry(blogListPath(1, c.slug), localesFor(arabic.filter((p) => p.category?.slug === c.slug)))),
        ...posts.flatMap((p) => entry(blogPostPath(p.slug), p.available_locales, parseCmsDate(p.updated_at), 0.7)),
    ];
}
```

```ts
export function blogPosting(post: BlogPost, path: string, locale: Locale): Node {
    const plain = text(post.body?.replace(/<[^>]+>/g, ' '));
    return compact({
        '@type': 'BlogPosting',
        '@id': entityId(path, locale, 'article'),
        headline: capHeadline(text(post.title)),
        description: text(post.seo_description) ?? text(post.excerpt),
        image: post.cover?.full_url,
        datePublished: toIsoDate(post.published_at),

        // A deleted author leaves the organization as the author.
        author: (post.author && person(post.author)) || { '@id': ORGANIZATION_ID },
        publisher: { '@id': ORGANIZATION_ID },
        mainEntityOfPage: { '@id': pageId(path, locale) },
        isPartOf: { '@id': blogId(locale) },
        articleSection: text(post.category?.name),
        keywords: (post.tags ?? []).map(text).filter(Boolean).join(', '),
        wordCount: plain ? plain.split(' ').length : undefined,
        inLanguage: locale,
        url: pageUrl(path, locale),
    });
}

export function faqPage(faqs: BlogPost['faqs'], path: string, locale: Locale): Node | null {
    const items = (faqs ?? []).filter((f) => text(f.question) && text(f.answer));
    if (!items.length) return null;
    return {
        '@type': 'FAQPage',
        '@id': entityId(path, locale, 'faq'),
        mainEntity: items.map((f) => ({
            '@type': 'Question',
            name: text(f.question),
            acceptedAnswer: { '@type': 'Answer', text: text(f.answer) },
        })),
    };
}

        name: text(name),
        description: text(description),
```

`app/components/blog/listing-metadata.ts`:

```ts
import type { Metadata } from 'next';
import { getBlogCategories, getBlogPosts } from '@/lib/blog-data';
import { blogListPath } from '@/lib/blog';
import { fmt, localeAlternates, ogLocale, type Locale } from '@/lib/i18n/config';
import { getMessages } from '@/lib/i18n/server';
import { metaDescription } from '@/lib/seo';

export async function listingMetadata({ locale, page, category }: { locale: Locale; page: number; category?: string }): Promise<Metadata> {
    const t = getMessages(locale).blog;
    const [listing, categories] = await Promise.all([getBlogPosts(locale, page, category), getBlogCategories(locale)]);
    const current = category ? categories.find((c) => c.slug === category) : undefined;
    if (category && !current) return { title: t.meta.notFoundTitle, robots: { index: false, follow: false } };

    const baseTitle = current ? (current.seo_title || fmt(t.meta.categoryTitle, { name: current.name ?? current.slug })) : t.meta.title;
    const title = page > 1 ? fmt(t.meta.pageTitle, { title: baseTitle, page }) : baseTitle;
    const description = metaDescription(current?.seo_description, current?.description, t.meta.description);
    const path = blogListPath(page, category);

    return {
        title,
        description,
        alternates: localeAlternates(path, locale),
        openGraph: { title: `${title} | Codetoon`, description, type: 'website', locale: ogLocale[locale] },
        // An empty listing (e.g. Arabic before any translation) shouldn't be indexed.
        ...(listing.total === 0 && { robots: { index: false, follow: true } }),
    };
}
```

```tsx
import type { Metadata } from 'next';
import Image from 'next/image';
import Link from 'next/link';
import { notFound, redirect } from 'next/navigation';
import JsonLd from '@/app/components/JsonLd';
import ArticleCta from '@/app/components/blog/ArticleCta';
import ArticleFaq from '@/app/components/blog/ArticleFaq';
import ArticleToc from '@/app/components/blog/ArticleToc';
import AuthorBox from '@/app/components/blog/AuthorBox';
import BlogCard from '@/app/components/blog/BlogCard';
import { getBlogPost, getRelatedBlogPosts } from '@/lib/blog-data';
import { blogListPath, blogPostPath, extractToc, formatBlogDate, MIN_TOC_HEADINGS, shouldRedirectToEnglish } from '@/lib/blog';
import { fmt, localeAlternatesFor, localizePath, ogLocale } from '@/lib/i18n/config';
import { getMessages, resolveLocale } from '@/lib/i18n/server';
import { metaDescription, ogImages, pageTitle } from '@/lib/seo';
import { blogPosting, breadcrumbs, entityId, faqPage, graph, webPage } from '@/lib/structured-data';

export const revalidate = 300;

type Props = { params: Promise<{ locale: string; slug: string }> };

export async function generateMetadata({ params }: Props): Promise<Metadata> {
    const locale = await resolveLocale(params);
    const { slug } = await params;
    const post = await getBlogPost(slug, locale);
    const t = getMessages(locale).blog;

    if (!post) return { title: t.meta.notFoundTitle, robots: { index: false, follow: false } };
    if (shouldRedirectToEnglish(post.available_locales, locale)) return {};

    const path = blogPostPath(slug);
    const title = pageTitle(post.seo_title || post.title, t.meta.title);
    const description = metaDescription(post.seo_description, post.excerpt);
    return {
        title,
        description,
        alternates: localeAlternatesFor(path, locale, post.available_locales),
        openGraph: {
            title: `${title} | Codetoon`,
            description,
            type: 'article',
            locale: ogLocale[locale],
            publishedTime: post.published_at,
            modifiedTime: post.updated_at,
            section: post.category?.name ?? undefined,
            tags: post.tags ?? undefined,
            images: ogImages(post.cover?.full_url),
        },
    };
}

export default async function BlogPostPage({ params }: Props) {
    const locale = await resolveLocale(params);
    const { slug } = await params;
    const post = await getBlogPost(slug, locale);
    if (!post) notFound();

    const path = blogPostPath(slug);
    // Arabic only exists once translated; until then the English post is the page.
    if (shouldRedirectToEnglish(post.available_locales, locale)) redirect(localizePath(path, 'en'));

    const t = getMessages(locale);
    const related = await getRelatedBlogPosts(slug, locale);
    const toc = extractToc(post.body);

    const jsonLd = graph(
        webPage({ path, locale, name: post.title ?? slug, description: post.seo_description || post.excerpt || undefined, image: post.cover?.full_url, mainEntityId: entityId(path, locale, 'article'), dateModified: post.updated_at }),
        breadcrumbs(path, locale, [
            { name: t.blog.meta.title, path: '/blog' },
            ...(post.category ? [{ name: post.category.name ?? post.category.slug, path: blogListPath(1, post.category.slug) }] : []),
            { name: post.title ?? slug, path },
        ]),
        blogPosting(post, path, locale),
        faqPage(post.faqs, path, locale),
    );

    return (
        <article className="px-5 pt-32 pb-20 sm:pt-40">
            <JsonLd data={jsonLd} />
            <div className="mx-auto w-full max-w-[760px]">
                <header>
                    {post.category && (
                        <Link href={localizePath(blogListPath(1, post.category.slug), locale)} className="inline-flex rounded-full bg-[#e6f0f8] px-3.5 py-1.5 text-[13px] font-semibold text-[#0d71ba]">
                            {post.category.name}
                        </Link>
                    )}
                    <h1 className="mt-5 text-[32px] font-bold leading-tight text-[#000305] sm:text-[44px]">{post.title}</h1>
                    <div className="mt-5 flex flex-wrap items-center gap-x-4 gap-y-1 text-[15px] text-[#718096]">
                        {post.author?.name && <span className="font-semibold text-[#2d3748]">{post.author.name}</span>}
                        <time dateTime={post.published_at}>{fmt(t.blog.post.publishedOn, { date: formatBlogDate(post.published_at, locale) })}</time>
                        {post.reading_time && <span>{fmt(t.blog.list.minRead, { minutes: post.reading_time })}</span>}
                    </div>
                </header>

                {post.cover?.full_url && (
                    <div className="relative mt-8 aspect-[16/9] overflow-hidden rounded-[24px] bg-[#EFF5FB]">
                        <Image src={post.cover.full_url} alt={post.cover_alt || fmt(t.blog.post.coverAltFallback, { title: post.title ?? '' })} fill priority sizes="(min-width: 800px) 760px, 100vw" className="object-cover" />
                    </div>
                )}

                {toc.length >= MIN_TOC_HEADINGS && <div className="mt-10"><ArticleToc items={toc} title={t.blog.post.toc} /></div>}

                {post.body && <div className="prose-article mt-10" dangerouslySetInnerHTML={{ __html: post.body }} />}

                {post.faqs && post.faqs.length > 0 && <ArticleFaq faqs={post.faqs} title={t.blog.post.faq} />}

                {post.tags && post.tags.length > 0 && (
                    <div className="mt-10 flex flex-wrap items-center gap-2" aria-label={t.blog.post.tags}>
                        {post.tags.map((tag) => (
                            <span key={tag} className="rounded-full border border-[#E6E7E8] px-3 py-1 text-[13px] text-[#535556]">#{tag}</span>
                        ))}
                    </div>
                )}

                {post.author && <AuthorBox author={post.author} label={t.blog.post.writtenBy} />}

                <ArticleCta slug={slug} />
            </div>

            {related.length > 0 && (
                <section className="mx-auto mt-20 w-full max-w-[1200px]" aria-labelledby="related-title">
                    <h2 id="related-title" className="mb-6 text-[28px] font-bold text-[#000305]">{t.blog.post.related}</h2>
                    <div className="grid gap-6 sm:grid-cols-2 lg:grid-cols-3">
                        {related.map((p) => <BlogCard key={p.id} post={p} locale={locale} />)}
                    </div>
                </section>
            )}
        </article>
    );
}
```
